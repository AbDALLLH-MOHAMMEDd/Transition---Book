What is CSS Transition?

The Transition property allows you to change property values smoothly over a given duration. Instead of the element changing its state instantly (like jumping from one color to another), the browser creates an animation effect over the specified time (e.g., 0.4s 0.4s), making the user interface feel much smoother and more professional.
